Front-end e Back-End

Antes de entender o que é um backend, também é importante entender outro conceito do desenvolvimento de sistemas, isso pois são conceitos que ainda distindos andam juntos.

Front-End

Basicamente, o Front-End é a interface gráfica do projeto. Ou seja, onde se desenvolve a aplicação o qual o usuário pode interagir diretamente, seja em sites, aplicativos ou softwares.

Back-End

O Back-End é onde o código acontece de forma mais lógica e complexa, como por exemplo, onde os dados do usuário devem ser usados e armazenados. Resumidamente é a parte no qual o usuário não consegue interagir.

Qual a diferença entre os dois?

A diferença fica muito clara só de saber o significado entre os dois termos, mas, sintetizando, a front é onde o usuário v~e e interage, e o back é onde a parte lógica do sistema acontece.

Qual a responsabilidade de cada um deles?

A responsabilidade do Front-End é apresentar uma interface gráfica no qual o usuário consiga interagir para concluir qual que seja o objetivo dele no sistema, portanto deve ser uma estrutura intuitiva e bem pensada, pois de nada adianta ter um front-end esteticamente lindo, mas que atrapalhe a utilização do usuário. Por outro lado, o back-end se responsabiliza por assegurar que a comunicação entre o usuário e o sistema seja feita de forma lógica e que funcione.

Como eles se comunicam?

A integração entre o front e o back é feita através de uma API. Uma API (Application Programming Interface), é a ponte que permite que essas duas partes se comuniquem. Em aplicações web, é usado o API REST que tem como base da comunicação o protocolo HTTP. O cliente, utilizando o front-end, envia uma requisição através do protocolo HTTP para o servidor (back-end), e essas ações podem ser: adicionar, ler, excluir ou atualizar dados. este tipo de arquitetura é chamada de cliente servidor. Por exemplo quando o usuário interage clicando em um botão, o front envia uma requisição para o back-end, por sua vez o back-end processa essa requisição, realiza as operações necessárias, como consulta nos dados, e por fim, envia uma resposta para o front-end.

3 tipos de API

Tipo Descrição
Privadas São utilizadas internamente entre as aplicações de uma empresa, ou seja, de forma local.
Parceiros Usadas entre parceiros de negócio ou para permitir a integração de diferentes softwares.
Públicas Podem ser utilizadas por empresa que os desenvolvedores possa fazer a integração entre diferentes softwares.

Onde o Back-End é executado

O código do back-end é executado em servidores físicos, ou seja, máquinas melhores que s0ão mantidas em locais próprios da empresa ou data centers. O código também pode ser executado em plataformas gerenciadas pela internet, como a AWS (Amazon Web Services), Google Cloud Plataform (GCP) e Microsoft Azure. Ademais, tecnologias como o Docker, que empacota o sistema para rodar de maneira isolada em qualquer servidor.
